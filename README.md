# Nikhil-- 3D Creator Portfolio

A dark 3D creator portfolio landing page built with React, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Then open the Vite local URL, usually:

```text
http://localhost:5173
```

## Build

```bash
npm run build
```

## Main files

- `src/App.tsx` - all sections, animation components, image data, and reusable buttons
- `src/index.css` - global reset, Kanit Google Font import, Tailwind setup, gradient heading class
- `tailwind.config.js` - Tailwind content and font setup
